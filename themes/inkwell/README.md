# Inkwell

A typographic theme for writers, blogs and newsletters: warm paper, ink-black
text, an oxblood accent and marbled endpapers for covers.

## Pages

| Template | What it is |
| --- | --- |
| `home` | A newspaper-style masthead, the latest essay, three recent posts, a pull quote and the subscribe box |
| `blog-index` | The archive: every essay in rows, grouped by year |
| `post` | An essay: label, title, italic dek, byline, cover, body text, pull quote, list and author box |
| `about` | The writer, what the publication covers, and the subscribe box |
| `contact` | Email, post and talks, in a reading column |
| `404` | "This page is a blank margin" |

## Components

- **Header**: the publication name in italic, three links and a Subscribe button.
- **Footer**: the name, a line about the letter, links and fine print on ink.
- **Subscribe box**: points to `/members/register`, so readers become members of your site.
- **Author box**: initials in a circle, a short bio and a link to About.

## Design

- **Type**: Newsreader for headlines and reading text, Figtree for menus, labels and meta.
- **Colour**: paper `#FAF8F3`, ink `#1C1B19`, oxblood `#8E2B25`, card stock `#F1ECE2`.
  All text meets WCAG AA contrast.
- **Measure**: the reading column is `40rem`, about 68 characters.
- **Images**: six marbled-paper artworks, generated for this theme, each under 350 KB.
