# Summit

A bold, poster-style theme for conferences, festivals, meetups and launch days:
night navy, tangerine and lime, shapes instead of stock photos, and big
grotesque type that reads from the back of the room.

## Pages

| Template | What it is |
| --- | --- |
| `home` | Poster hero with date badge and key numbers, speakers, day one of the schedule, tickets, the venue, sponsors and a ticket band |
| `schedule` | Both days: time, talk, speaker and room, one row each |
| `speakers` | Twelve speakers as colour tiles with initials |
| `tickets` | Three tiers and questions and answers |
| `about` | Why the event exists and its code of conduct, in three cards |
| `blog-index` | News from the organisers |
| `contact` | Addresses for tickets, speaking and sponsoring |
| `404` | "This session was cancelled" |

## Components

- **Header**: the event mark and name, four links and a lime Get tickets button.
- **Footer**: the name, date and place, links and fine print on navy.
- **Ticket band**: a tangerine call to action placed above the footer.

## Design

- **Type**: Bricolage Grotesque for headlines and numbers, Space Grotesk for everything else.
- **Colour**: navy `#0B1026`, tangerine `#FF5A36`, lime `#C6FF3D`, blue `#3D5AFE`,
  paper `#F5F3EE`. Text tokens meet WCAG AA contrast; tangerine text on paper
  uses the darker `ink.accent`.
- **Speakers**: tiles with initials, so a site works before anyone has sent a photo.
  Swap in a photo per speaker whenever you have one.
- **Images**: four poster artworks, generated for this theme, each under 350 KB.
